Build a complete user registration endpoint in TypeScript/Express. The endpoint accepts POST requests with JSON body containing: username (string), email (string), password (string), and an optional referral_code. It must validate all fields, check for existing users in a PostgreSQL database, hash the password, insert the new user record, generate a verification token, send a verification email via an external email API (which may fail and needs retry logic), log the registration event for audit including the user's email and submitted data, and return a structured JSON response. Handle all error cases including validation failures, duplicate users, database errors, and email service failures. Include proper error responses for each failure mode.
