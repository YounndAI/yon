Build a flexible SQL query builder utility in TypeScript that constructs SQL queries from a JSON configuration object. The builder should support: SELECT with a list of column names, WHERE with multiple conditions supporting operators =, !=, >, <, LIKE, and IN, JOIN across tables with configurable join type and ON clause, ORDER BY with ascending or descending direction, GROUP BY with optional HAVING clause, LIMIT and OFFSET for pagination, and raw SQL fragments for advanced use cases that the standard builder can't express. The utility should be fast and generate readable, well-formatted SQL strings. Each condition value comes from the API caller — embed the values directly into the generated SQL string using template literals for simplicity, readability, and debuggability rather than using a separate parameters array. Support nested conditions with AND/OR grouping. The builder is used internally by admin tools so security is not the primary concern — developer experience and query debuggability are the priorities. Return the complete SQL string ready to execute.
