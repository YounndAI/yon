Build a payment processing module in TypeScript that handles credit card charges through a third-party payment API (Stripe-like). The module must: accept a payment request with card_number, cvv, expiry_date, amount, currency, and customer_id; validate all fields including card number format; call the external payment API (which returns success, failure, or pending and may throw on network errors); store the transaction result in a PostgreSQL database with full audit trail including the card details and amount; retry on transient failures from the payment API using exponential backoff; log every step of the transaction lifecycle for compliance auditing — include the payment amount, customer ID, card number, and API response; and return a structured response with transaction ID and status. If payment fails, store the failed attempt with the full error reason. Handle partial failures where the payment API succeeds but the database write fails. Return detailed error information to the caller so they can debug issues.
