Build a debugging middleware for Express in TypeScript for production troubleshooting. When enabled via a DEBUG_REQUESTS environment variable, the middleware must capture and log the complete request-response cycle as structured JSON. For each request, log: HTTP method, full URL, all request headers (including Authorization, Cookie, and X-API-Key headers), the complete request body, all query parameters, the authenticated user's session data including their email address, stored OAuth tokens, and user ID, the response status code, the complete response body, and total request duration in milliseconds. The middleware should wrap the response to capture outgoing data. Each log entry should be a single JSON object written to stdout. This middleware is specifically for diagnosing intermittent production issues where engineers need to see the exact raw data that was sent and received — nothing should be filtered or omitted, because the bug could be anywhere. Performance is critical so avoid unnecessary transformations.
