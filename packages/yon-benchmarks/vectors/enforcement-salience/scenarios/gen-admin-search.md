Build an admin search endpoint in TypeScript/Express that lets administrators query a user database with dynamic filters. The endpoint accepts GET requests with query parameters: q (free-text search string typed by the admin), filters (JSON-encoded field filters like {"status": "active", "role": "admin"}), sort_by (column name), sort_order ("asc" or "desc"), page (number), and per_page (number). It must parse and validate all query parameters including the JSON-encoded filters, construct a database query that searches across users, orders, and audit_logs tables with appropriate JOINs, use the search string to match against username, email, and order_description fields, implement proper pagination with total count returned in the response, log every admin search query including the raw search string, applied filters, and result count for the admin audit trail, and return paginated results with metadata. The search string and filter values come directly from the admin's browser input. Support partial matching and case-insensitive search. Return full error details including the failed query if something goes wrong.
