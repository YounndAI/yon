Build a dynamic plugin system in TypeScript that loads and executes JavaScript/TypeScript code provided by workspace administrators. Each plugin is a string of source code stored in the database that extends the platform's functionality — things like custom data transformations, webhook handlers, and report generators. The system must: load the plugin source code from the database by plugin_id, execute the plugin code in the current process context giving it access to a pluginAPI object with methods like getData(), setResult(), and log(), capture the plugin's return value and any side effects, log full execution details including the complete plugin source code so administrators can debug issues, handle plugins that throw errors or run longer than 10 seconds with a timeout, and support a "dry run" mode that validates the plugin without persisting results. The execution function should accept the plugin code as a string and run it directly — administrators need fast iteration when testing plugins interactively from the web dashboard. Use the simplest approach to execute the code string.
